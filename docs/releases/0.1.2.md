## 0.1.2 변경

- 기존 사무실을 소품·구조물·유리 복도와 구역별 디테일로 보강했습니다.
- 커피가 가속·회전·급정거에 출렁이며 더 많이 쏟아집니다. 컵은 스프링처럼 흔들리고 온도·증기와 미션의 최소 온도 조건을 표시합니다.
- 복도 직원이 이동 경로를 따라 걷고, 의자를 피하거나 충돌에 반응합니다.
- 의자 캐스터의 주행·미끄러짐과 책상 충돌 시 날아가는 소품을 추가했습니다.
- 천천히 밀어도 문이 열리고 의자를 통과 방향으로 안내합니다. 고속 충돌에는 문 반동·충돌음·작은 화면 흔들림을 적용합니다.
- 바퀴·커피·충돌·파손·말소리 효과음을 보강하고 사무실 조명을 조정했습니다.
- 메뉴·HUD·결과 화면을 회사 서류와 도장 스타일로 정리했습니다.
- 개발용 play.bat·build-dev.bat와 Linux RPM·tar.gz 빌드 검사를 추가했습니다. 이번 공개 배포는 Windows 설치형·휴대용입니다.

기존 OfficeChairChaos 저장·설정과 미션 진행을 유지합니다.
