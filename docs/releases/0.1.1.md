## 0.1.1 변경

- **설치형 Windows 버전**을 추가했습니다. 시작 메뉴·선택형 바탕 화면 바로 가기와 제거 기능을 제공합니다.
- 게임 시작 시 새 버전을 알리고 설정의 **업데이트**에서 확인·설치할 수 있습니다. 동의 후 진행 저장 → 다운로드·체크섬 검증 → 설치 → 재실행하며, 실행 확인 실패 시 이전 버전으로 복구합니다. 자동 확인은 설정에서 끌 수 있습니다.
- 릴리즈 첨부는 **설치 EXE·휴대용 ZIP·체크섬 세 개**로 정리했습니다. 여러 크레딧·라이선스의 전문은 패키지 안의 `LICENSES.txt`와 게임의 라이선스 화면에 모았습니다.
- 의자 뒤에서 **E로 양손 손잡이를 잡고 앞으로 미는 조작**을 추가했습니다. 마우스로 양손을 잡아도 활성화됩니다.
- 밀기 중 **W/S 전후진, A/D 조향, Shift 부스트, Space 제동**을 사용합니다. 카메라를 돌려도 전진 방향이 바뀌지 않습니다.
- 착석한 부장님을 손잡이 대신 잡던 문제를 수정했습니다.
- 밀기 자세와 균형 복원을 보강하고 넘어짐 허용 범위를 넓혔습니다. 적재 상태 검사에서 일반 밀기 약 2.6m/s, 직진 부스트 약 5.1m/s를 기록했습니다.
- 고속 급회전·급제동·충돌에서는 좌석 연결이 풀리고 부장님이 관성 방향으로 떨어집니다. 떨어진 뒤에는 다시 잡아 수습할 수 있습니다.
- 커피가 가속·기울기·낙하에 더 크게 반응합니다. 정지 상태의 관절 잡음은 필터링합니다.
- HUD에 밀기 조작, 속도, 커피와 부장님 상태를 표시합니다.

기존 저장과 진행을 그대로 사용할 수 있습니다.
