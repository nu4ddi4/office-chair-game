0.1.1·0.1.2에서 넘어오실 때는 이 릴리즈의 설치 파일을 직접 받아 주세요. 0.1.3부터 게임 내 업데이트 확인이 현재 저장소를 사용합니다. Debian·Ubuntu에서는 해당 버전의 amd64 DEB를 바로 받을 수 있습니다.

- 이어하기에서 커피 온도를 복원하고, 마지막 주차를 마쳤으면 퇴근 길부터 다시 시작합니다.
- 뒤쪽 손잡이 두 개를 잡으면 앞으로 밀 수 있습니다. 고속 코너에서 커피가 더 출렁이고 부장님이 더 쉽게 떨어지며, 손이 풀리면 화면에 표시됩니다.
- 경유점은 표시된 원에 들어가면 통과합니다. 자료실 업무에서는 한 손으로 문을 열고, 송풍 구간에서는 리본으로 바람 세기를 확인할 수 있습니다.
