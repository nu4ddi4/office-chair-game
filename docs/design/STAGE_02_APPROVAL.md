# 02 — 팀장님 동의만 받으면 됩니다

[전체 설계](DENSE_STAGES.md) · [이전 스테이지](STAGE_01_PRINT.md) · [다음 스테이지](STAGE_03_SHUTDOWN.md).

상태: 구현 전 상세 스크립트. 실제 NPC 대화와 현장 물체 조작이 같은 승인 절차 안에서 이어진다.

## 1. 이 스테이지가 하는 일

출력한 서류를 팀장에게 내밀면 끝날 것처럼 시작한다. 팀장은 동의하지만 결재석과 빈 회의 의자들이 움직이기 시작한다. 플레이어는 이야기를 듣고 정답 번호를 고르는 대신, 브레이크·서류 트레이·이동 경로를 직접 다룬다.

NPC는 설비가 이상하다는 걸 알고도 업무 절차에 집중한다. 플레이어가 순서를 바꾸거나 물건을 바꿔 놓으면 그 행동을 짧게 알아본다.

| 항목 | 목표 |
| --- | --- |
| 화면 제목 | 팀장님 동의만 받으면 됩니다 |
| 목표 | 퇴근 신청서에 결재를 받으세요. |
| 첫 플레이 | 4~6분 |
| 숙련 경로 | 1분 40초~2분 30초 |
| 주요 조작 | NPC 대화, 서류 놓기, 브레이크, 이동하는 트레이 접근 |
| 핵심 판단 | 결재석을 따라갈지 멈출지, 접근할 면과 물건을 어떻게 쓸지 |
| 대표 장면 | A01: 빈 의자까지 회의 참석자로 모임 / A02: 팀장이 젖혀진 채 기계 도장이 결재 |
| 주요 소구간 | A-A 접수, A-B 이동 결재석, A-C 승인 서류 회수 |
| PC 파손 | 없음. 이 단계에서도 장치 규칙을 실험 가능 |

## 2. 공간과 사물

기존 오세진의 담당 공간 옆에 이동식 결재석과 작은 회의 준비 구역을 둔다. 현재 맵의 책상·문·기본 인물 충돌을 없애서 만들지 않는다. 이동 연출이 필요한 오세진은 그 구간용 별도 인스턴스로 두고 기존 원본은 해당 스테이지 동안만 숨긴다. 중복 NPC가 보이거나 두 충돌체가 겹치지 않게 한다.

```text
               북쪽 / 마지막 PC 구역으로 가는 문
                        [승인 서류 받침대]
                               |
          [브레이크 접근면] [기계 도장 / 결재석]
                 ┌─────────────┐
                 │  오세진의 이동 궤도  │
                 └─────────────┘
                  ↑                  ↑
              의자 C1             의자 C2
                    [회의 참가 표지]
                               |
               [원본 서류함] [컵 받침] [낮은 제동턱]
                               |
                       시작 / 한지우
```

### 경로 계약

- 결재석은 4.8×3.0m의 둥근 사각 경로를 돈다. 기본 속도 0.85m/s, 네 모서리에서 1.0초씩 멈춘다.
- 출구 쪽 직선에는 서류를 놓기 쉬운 폭 2m의 접근 공간이 있다. 어떤 경로에서도 고속 회전 표적을 맞히게 하지 않는다.
- 빈 회의 의자 C1/C2는 각각 폭 1.1m의 고정 경로로 결재석 앞에 모인다. 동시에 플레이어를 양쪽에서 끼우지 않는다.
- 의자와 바퀴에 방향이 보이고 바닥에 닳은 흔적이 있다. 레일이 보이지 않아도 대략적인 움직임을 예측할 수 있다.
- 브레이크는 시각적으로 큰 금속 페달이며 정지하면 바퀴 아래에 쐐기가 내려간다. 단순히 버튼 색만 바꾸지 않는다.
- 도장의 위험 범위는 책상 위 작은 사각형이다. 바닥 동선을 갑자기 내려치는 함정으로 만들지 않는다.
- 도장을 받는 트레이·종이를 꺼내는 트레이·브레이크의 타깃을 분리한다. 같은 F 입력이 대화와 장치에 동시에 들어가지 않는다.

## 3. 인물

**오세진 (`oh`, 보안팀장).** 요청을 처리하려는 의지는 있다. 이동하는 회사 설비를 당연하게 취급한다. 말투는 짧고 진지하다. 플레이어에게 일부러 거짓 단서를 던져 오답을 유도하지 않는다.

**한지우 (`han`, 프로젝트 개발).** 옆 작업대에서 결재 진행 표시를 보고 있다. 상태가 이상할 때 짧게 지적한다. 플레이어가 브레이크를 못 찾는다고 풀이를 해설하지 않는다.

**서유진 (`seo`).** 이전 공간에 남는다. 돌아가 말하면 출력실 사건에 대한 한 문장만 답한다. 되돌아가야 받을 수 있는 필수 아이템은 없다.

## 4. 시작 — A-A 접수

### A-00 / 가져온 서류

첫 진입 시 서류는 시작 지점 원본 서류함에 놓여 있다. 손에 든 채 시작해 시야를 막지 않는다. 이전 구간에서 들고 넘어왔다면 손 상태를 그대로 인정하고 서류함 복제본은 생성하지 않는다.

화면:

```text
STAGE 02 · 팀장님 동의만 받으면 됩니다
퇴근 신청서에 결재를 받으세요.
```

한지우 `A_HAN_OPEN`:

> 팀장님도 퇴근하고 싶어 하세요.

오세진은 서류함 쪽을 본다. 최초 대화는 접근 후 F로 시작하며, 플레이어가 먼저 서류 트레이를 만져도 같은 접수 절차가 시작된다.

### A-01 / 첫 대화 원문

오세진 `A_OH_ASK`:

> 오늘 업무는 마쳤어요?

선택:

| 선택 ID | 노출 문구 | 오세진 반응 | 진행 영향 |
| --- | --- | --- | --- |
| `A_YES` | 네. 퇴근 신청입니다. | 그럼 잠깐 확인하죠. | 접수 가능, 첫 회의 의자 이동 예약 |
| `A_READ` | 서류부터 볼게요. | 보시고 여기 놓으세요. | 대화 종료, 원본 회수·트레이 조작 가능 |
| `A_CHAIR` | 의자에 바퀴가 너무 많은데요. | 이동 결재석입니다. | 대화 종료, 접수 가능 |

선택 중 어느 것도 사망·오답이 아니다. 문장을 읽은 뒤 자연스럽게 현장으로 돌아가게 한다. 선택 목록은 세로로 정상 배치하고 마우스 오버·키보드 포커스로 게임 밖 커서 설정을 바꾸지 않는다.

대화 중에는 의자, 결재석, 도장 타이머가 멈춘다. 대화가 닫힌 뒤 예약한 사건이 진행한다. 사용자의 읽기 속도가 의자 충돌을 결정하지 않는다.

### A-02 / 서류 접수

원본을 들고 접수 트레이 앞에서 F:

```text
F — 서류 놓기
```

트레이 화면:

```text
REQUEST R41
RECEIVED
APPROVAL PENDING
```

정상 접수음은 1스테이지 출력 성공음과 동일하다. 작은 종이 고정쇠가 닫히고 서류 상단에 ‘접수’ 표시가 찍힌다. 아직 ‘승인’ 표시가 아니다.

접수 상태를 체크포인트 A-A로 저장한다. 성공하면 이후 실패·재실행에서 출력실을 다시 하지 않는다. 저장 실패 시 접수된 서류는 그 자리에서 유지하고 같은 저장을 재시도할 수 있다.

## 5. 첫 사건 — A01 빈 의자도 참석한다

### A-03 / 기대를 만들기

접수 또는 `A_YES` 대화 종료 중 먼저 발생한 이벤트가 사건을 한 번 예약한다. 서류가 아직 접수되지 않았으면 빈 의자 이동만 먼저 일어나고 결재석은 기다린다.

| 상대 시각 | 사물·표시 | 플레이어가 할 수 있는 것 |
| --- | --- | --- |
| 0.00 | 책상 화면에 ‘퇴근 검토’ 한 줄 | 자유 이동 |
| 0.35 | 오세진이 의자를 조금 뒤로 민다 | 브레이크 접근 가능 |
| 0.80 | 빈 의자 C1의 바퀴가 돌아가기 시작 | 길을 비키거나 막기 |
| 1.40 | C1이 회의 위치에 들어오며 참석 1 증가 | 의자 브레이크 가능 |
| 2.00 | 다른 쪽 C2도 움직임 | 앞에서 본 규칙 활용 가능 |
| 2.70 | 빈 의자 둘이 책상 앞에 나란히 정렬 | 빈 좌석을 직접 확인 |
| 3.10 | 화면이 ‘참석 3 / 발언 0’으로 갱신 | 서류 놓기·장치 조작 계속 가능 |
| 3.80 | 오세진이 빈 의자 쪽으로 고개를 끄덕임 | 카메라 강제 이동 없음 |

화면의 참석 3은 오세진과 빈 의자 두 개를 센다. 사람 수를 센다고 설명하지 않는다. 플레이어가 C1을 막으면 참석은 2로 남고 그 의자는 조용히 기다린다. 막은 행동이 무효화되지 않게 한다.

오세진 `A_OH_ATTEND`, 0.6초 쉰 뒤:

> 다들 오셨네요.

### A-04 / 의자에 대한 플레이어 행동

| 행동 | 결과 |
| --- | --- |
| C1/C2 앞에 서기 | 0.7m 앞에서 속도를 줄이고 정지. 일정 시간 뒤 돌진하지 않음 |
| 빈 의자 브레이크 F | 그 자리에서 멈추고 참석 숫자는 현재 상태를 유지 |
| 빈 의자 `F — 참석` | 카메라를 굴리지 않고 앉은 높이로 천천히 낮춤, ‘안건 1 / 99’ 표시 |
| 참석 중 F 또는 이동 입력 | 즉시 일어나기. 회의를 끝까지 기다릴 필요 없음 |
| 의자 위에 점프 | 의자 이동을 유지하되 낮은 속도로 안전 이동 가능 |
| 의자를 옆으로 밀기 | 표시된 짧은 범위 안에서 경로를 변경하고 NPC가 한 번 반응 |

앉아서 안건을 기다리면 2초 후 한지우가 한 번만 말한다.

한지우 `A_HAN_AGENDA`:

> 첫 안건이 퇴근 회의 날짜래요.

이 대사는 목표를 설명하는 힌트가 아니다. 플레이어가 회의를 구경하는 선택에 대한 보상이다. 대기만 하면 진행하는 가짜 정답 경로는 두지 않는다.

## 6. 중심 문제 — A-B 움직이는 결재석

### A-05 / 서류는 접수됐는데 책상이 움직인다

서류가 접수되고 첫 의자가 도착하면 결재석이 이동 궤도를 따라 천천히 움직인다. 브레이크를 미리 걸었다면 이동하지 않고 오세진의 몸과 의자 등받이만 한 번 작게 출렁인다. 주요 의자 집합 장면 A01은 그대로 남는다.

오세진 `A_OH_MOVING`:

> 처리 중입니다. 잠시만요.

트레이 화면:

```text
REQUEST R41
DESK MOVING
STAMP STANDBY
```

플레이어가 다시 대화하면 한 번만 다음 선택을 준다.

| 선택 | 대사 | 실제 변화 |
| --- | --- | --- |
| 잠깐 멈춰 주실래요? | 저도 멈추고는 싶은데요. | 대화 종료 뒤 1초간 끝 정지 시간을 추가. 영구 정지는 안 됨 |
| 서류는 어디에 있나요? | 접수함에 잘 있습니다. | NPC가 실제 트레이 쪽을 짧게 봄. 정답 경로 표시 없음 |
| 그냥 따라가 보겠습니다. | 이동 중에도 접수는 됩니다. | 대화 종료, 기존 경로 유지 |

세 선택을 번갈아 눌러 대사 타이머를 쌓을 수 없다. 동일 상태의 요청은 현재 추가 정지 시간만 갱신한다.

### A-06 / 정지시키는 기본 경로

1. 결재석 옆·뒤의 바퀴 페달로 접근한다.
2. `F — 브레이크`를 누른다.
3. 쐐기가 내려가고 결재석이 0.65초 동안 감속한다.
4. 의자 등받이가 뒤로 젖혀져 팀장이 반쯤 누운 자세가 된다.
5. 책상 위 도장 장치의 스탠바이 등이 켜진다.

브레이크 접근 실행 거리 1.25m. 페달이 넓고 어느 측면에서 조작하는지 실루엣으로 구분된다. 서류 트레이 F와 가까운 경우 화면 중앙에 더 가까운 쪽 하나만 잡는다. 대화 표시는 이 장치보다 멀 때 우선하지 않는다.

### A-07 / 따라가며 처리하는 대안

브레이크 없이 끝 정지 구간에 맞춰 트레이의 `F — 결재 요청`을 누를 수 있다. 누르는 즉시 도장 사이클을 예약하고 결재석은 그 위치에서 사이클 동안 정지한다. 성공 가능한 정지 창은 1초 이상이다.

이 대안은 ‘브레이크를 써라’는 내부 플래그 때문에 거절되지 않는다. 실행 거리·시야·정지 상태가 맞으면 같은 승인 결과로 이어진다.

### A-08 / 가구를 이용하는 대안

접힌 빈 의자를 경로의 낮은 제동턱에 세우면 결재석 앞 작은 안전 범퍼가 닿아 멈춘다. 의자가 가려져 보이지 않거나 너무 작으면 작동하지 않는다. 닿는 범퍼가 보이고 경로 밖에 0.8m 대피 공간이 있다.

정지 후 동일하게 결재 요청이 가능하다. 의자가 출구를 영구히 막으면 2초 뒤 접힌 상태로 옆 보관칸으로 이동한다. 물건을 이동시킨 플레이어 앞에서 이동 과정을 보여 준다.

한지우 `A_HAN_BLOCK`, 이 방법을 처음 썼을 때:

> 가구 배치는 승인됐네요.

브레이크·끝 정지·의자 범퍼 중 하나만 구현해 통과시키지 않는다. 첫 버전에서도 기본 경로와 끝 정지 대안은 작동해야 한다.

## 7. 승인 사건 — A02 누워도 결재는 된다

### A-09 / 도장 전

정지한 결재석에서 서류 옆 F:

```text
F — 결재 요청
```

화면:

```text
REQUEST R41
STAMP READY
```

도장 장치는 책상 위 보통 도장보다 훨씬 큰 회사 자산이다. 상단의 고무 패드가 아래로 내려오는 궤적을 먼저 보여 준다. 종이 아래 받침이 넓고 손을 넣어야 하는 조작이 아니다.

### A-10 / 승인 타이밍

| 상대 시각 | 연출 | 의미 |
| --- | --- | --- |
| 0.00 | 도장 장치의 작은 벨 1회 | 요청 접수 |
| 0.30 | 오세진이 누운 자세에서 서류를 봄 | 사람과 기계의 자세 대비 |
| 0.85 | 큰 도장이 0.4m 들어 올려짐 | 낙하 위치를 볼 시간 |
| 1.45 | ‘쿵’, 한 번 찍음 | 서류 승인 확정 |
| 1.75 | 바닥 의자 C2가 충격으로 0.25m만 밀림 | 작은 추가 결과 |
| 2.25 | 장치 옆 작은 영수증이 얇게 나옴 | 앞선 큰 동작과 대비 |
| 2.85 | 오세진 한마디 | 장면을 본 뒤 반응할 간격 |

오세진 `A_OH_STAMPED`:

> 자세는 좀 그래도 결재는 됩니다.

성공음은 1스테이지와 같고 음량도 같다. 거대한 도장을 찍었다고 시스템 알림을 전 화면에 크게 표시하지 않는다. 서류 위 ‘승인’과 출구의 상태등으로 결과가 남는다.

팀장을 제때 멈추지 않았더라도 이 사건은 강제 실패로 만들지 않는다. 끝 정지에서 요청한 경우 팀장은 정상 자세이고, 대신 빈 의자 두 개만 과장되게 뒤로 젖혀지는 변형을 사용한다.

## 8. 장난을 인식하는 분기

모든 분기는 같은 현장 조작을 이용한다. 전용 UI나 수십 줄짜리 대화를 새로 만들지 않는다.

| 행동 | 눈에 보이는 결과 | 대사 | 진행 보호 |
| --- | --- | --- | --- |
| 서류 대신 컵을 접수함에 놓음 | 컵 받침에 작은 ‘접수’ 잉크 자국 | 오세진: 커피는 제가 접수할게요. | 실제 서류는 원본함으로 돌아옴 |
| 이미 접수한 서류를 다시 줌 | 동일 요청 R41 표시, 복제 안 됨 | 이미 들어왔습니다. | 기존 상태 유지 |
| 팀장 뒤로 계속 따라감 | 한 바퀴 후 팀장이 고개만 돌림 | 제 출근 기록도 보시려고요? | 타이머·속도 증가 없음 |
| 동의하지 않겠다고 말함 | 빈 의자들이 정지해 기다림 | 그럼 서류는 여기 두세요. | 다른 경로로 승인 가능 |
| 승인 서류를 자기 의자에 놓음 | 의자 좌석에 승인 표시가 살짝 묻음 | 한지우: 저 자리는 먼저 퇴근하겠네요. | 서류는 훼손되지 않음 |
| 너무 오래 아무것도 안 함 | 팀장이 폼을 한 번 정리 | 대사 없음 | 실패·타임아웃 없음 |

선택지 ‘동의하지 않습니다’는 두 번째 대화 이후 추가 선택으로만 표시할 수 있다. 현재 세 개를 넘기면 일반 선택 하나를 교체한다. 실제 게임 종료·업데이트 동의창에는 이 기믹을 쓰지 않는다.

## 9. 실패와 복구

이 스테이지는 대부분의 실수를 가벼운 사고로 처리한다. 의자에 한 번 닿았다고 신청서가 사라지거나 승인 상태가 취소되지 않는다.

| 상황 | 즉시 결과 | 복구 |
| --- | --- | --- |
| 움직이는 결재석 앞을 막음 | 안전 범퍼가 감속 후 정지 | 플레이어가 비키면 0.6초 뒤 재출발 |
| 의자 두 개 사이로 들어감 | 하나가 멈추고 다른 하나만 0.5m 밀음 | 0.4초 뒤 자유 이동 |
| 회의 의자에 실수로 앉음 | 앉은 높이, 작은 안건 화면 | 이동/F로 즉시 일어나기 |
| 승인 전 서류를 떨어뜨림 | 원본 서류함으로 2초 뒤 복귀 | 접수 상태면 트레이로 복귀 |
| 승인 서류를 떨어뜨림 | 가까운 출구 받침대로 이동 | 승인 유지, 다시 집기 가능 |
| 책상 위 도장 위치에 뛰어듦 | 도장 안전센서가 멈추고 작은 ‘삑’ | 내려오면 사이클 재개, 피해 없음 |
| 소품을 출구에 쌓음 | 문 앞 정리 표시등 점멸, 접힌 소품만 옆으로 이동 | 문과 플레이어 충돌은 유지 |

뛰어든 플레이어를 도장이 때려 날리는 사고는 이 첫 버전에서 제외한다. 동일 장치가 종이를 찍는 판정과 인체를 감지하는 판정을 분명히 나눈다. 큰 폭발의 첫 등장은 다음 스테이지에 남긴다.

## 10. 완료와 마지막 업무 연결

완료 조건은 `approval == APPROVED` AND `document == EXIT_TRAY/HELD`다. 서류를 받침대에 놓거나 손에 든 채 출구로 가면 저장을 시도한다.

오세진 `A_OH_DONE`:

> 마지막 컴퓨터만 끄고 가세요.

복도 쪽에 보이는 PC 화면이 깜빡인다. 멀리서 바퀴가 아주 짧게 한 번 돈다. 도망갈 것이라고 설명하지 않는다.

한지우에게 추가 대화를 걸면:

> 저건 오늘 한 번도 자리를 안 지켰어요.

이 문장은 선택 대사다. 반드시 듣게 기다리지 않고 다음 공간으로 이동할 수 있다.

## 11. 상태·이벤트 계약

| 이벤트 | 전제 | 결과 |
| --- | --- | --- |
| `A_START_MEETING` | 최초 접수 또는 대화 종료 | C1/C2 이동 한 번 예약 |
| `A_SUBMIT` | 원본 문서가 손에 있음 | 요청 접수, 서류 트레이 보관, 체크포인트 A-A 저장 |
| `A_DESK_RUN` | 접수됨, 회의 의자 하나 이상 도착 | 결재석 순환. 사전 제동 상태면 정지 유지 |
| `A_BRAKE` | 실행 범위·시야 유효 | 결재석 감속, 바퀴 쐐기 내려감 |
| `A_BUMPER_STOP` | 의자와 안전 범퍼 실제 접촉 | 같은 정지 상태, 충돌 속도 제거 |
| `A_REQUEST_STAMP` | 접수됨, 정지 상태, 서류 있음 | 도장 사이클 예약, 그동안 정지 고정 |
| `A_STAMP_CONTACT` | 유효한 R41 서류 | 승인 한 번만 기록, 복제·중복 도장 방지 |
| `A_RECOVER` | 승인 문서 회수 | 손 슬롯 또는 출구 트레이에 이동 |
| `A_FINISH` | 승인·회수 완료 | 저장 성공 후 CLEAR 및 다음 공간 해금 |

대화 중 위험 상태와 이동 경로 시간을 함께 멈춘다. 메뉴에서 돌아온 첫 프레임에 도장 접촉이나 의자 이동량이 몰려 적용되지 않게 한다. 플레이어가 구간 밖으로 나가도 의자가 무한 추적하지 않는다.

회의 의자를 모두 미리 막아 결재석이 출발하지 않았어도, 접수된 서류와 정지 상태가 있으면 결재 요청을 허용한다. 승인 확정 후 남아 있는 출발 예약과 위험 이벤트는 취소한다. 성공한 뒤 늦게 도착한 의자가 승인을 무효로 만들지 않는다.

재실행 시 A-A 이전이면 원본함에서, A-A 이후면 접수 트레이·정지한 결재석 앞에서 시작한다. 승인 이후는 승인 상태를 유지한다. 접수와 승인에 각각 다른 표시를 써 저장 상태를 확인할 수 있게 한다.

## 12. 자산과 연출 제작량

| 자산 | 필요한 동작 | 재사용 |
| --- | --- | --- |
| 이동식 결재석 | 레일 없는 저속 이동, 정지, 브레이크 | 3스테이지 PC 이동 장치의 경로 제어 |
| 의자 C1/C2 | 바퀴 이동, 정렬, 뒤로 약간 젖힘, 접힘 | 1스테이지 의자와 같은 기본 모델 |
| 오세진 | 고개 보기, 몸 전체 젖힘, 정상 자세 복귀 | 얼굴 립싱크 없이도 장면 성립 |
| 기계 도장 | 상승·낙하·복귀·안전 정지 | 이후 출구 확인 단말과 회사 재질 통일 |
| 서류 | 원본·접수·승인 3개 표면 상태 | 1스테이지 신청서 인스턴스 |
| 화면 | 요청 상태, 참석 숫자, 짧은 안건 | 일반 HUD와 별도 작중 장비 화면 |

## 13. 웃음이 약할 때 고칠 순서

1. A01의 의자가 안 보이면 시작 배치와 이동 방향부터 바꾼다.
2. 빈 의자를 참석자로 센다는 것이 안 읽히면 화면 숫자 갱신과 의자 도착을 같은 시각에 맞춘다.
3. NPC 말만 웃기고 조작이 심심하면 끝 정지·브레이크·범퍼 대안의 실제 결과 차이를 강화한다.
4. 따라가기만 해서 피곤하면 경로를 짧게 하거나 코너 정지 시간을 늘린다.
5. A02를 보기 전에 지치면 접수 대화 한 턴을 삭제한다. 결재 절차를 더 추가하지 않는다.
6. 브레이크를 미리 써 큰 사건을 피한 사람에게는 의자들이 빈자리에서 동시에 젖혀지는 성공 변형을 준다.

## 14. 첫 구현 인수 조건

- 첫 대화 세 선택 모두 정답 암기 없이 진행할 수 있다.
- NPC에게 말하기 전 서류를 놓아도 절차가 시작된다.
- 빈 의자 도착과 참석 숫자가 실제 상태와 맞는다.
- 브레이크를 미리 걸거나 의자를 막은 행동이 실제 반영된다.
- 기본 제동 경로와 끝 정지 대안 둘 다 도장을 받을 수 있다.
- 대화·터미널·메뉴에서 물체가 멈추고 종료 후 부드럽게 이어진다.
- 타깃이 겹쳐 대화·브레이크·서류 놓기가 동시에 실행되지 않는다.
- 서류가 출구·바닥·장치 안에서 영구 유실되지 않는다.
- 정지한 팀장 변형과 정상 자세 변형 모두 성공 장면이 있다.
- 승인 저장이 실패하면 다음 스테이지로 넘어가지 않는다.
