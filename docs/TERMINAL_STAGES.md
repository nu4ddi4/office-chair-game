# 퇴근.exe · 출력실

현재 기본 게임은 **「한 장만 뽑아 주세요」 한 스테이지**다. 이전 여섯 스테이지와 임시 옥상 점프 코스는 교체했다. 메인 → 짧은 소개 → 1인칭 출력실 → 서류 전달 → 완료 순서로 진행한다.

## 플레이

출력 단말에서 `help`, `ls`, `cat`, `print <file>` 등을 사용한다. Enter 뒤 입력 포커스를 유지하고 ↑↓ 이력·Tab 완성·clear·history·exit를 지원한다. 옆에는 현재 목표만 표시한다.

출력을 시작하면 종이 더미 세 개가 실제 발판으로 쌓이고 사무용 의자가 밀려난다. 터미널의 pause/resume/cancel 또는 현장의 페달로 출력 상태를 바꾼다. 의자 브레이크도 조작할 수 있다. 터미널·대화·메뉴를 읽는 동안 물체와 종이 적재 시간이 멈춘다.

상부 트레이의 신청서를 F로 회수하고 결재 서류 접수함에 놓으면 출력이 종료된다. **명령 입력만으로 클리어되지 않는다.** 일찍 취소해 종이 발판이 부족하면 점검 발판차를 펼쳐 회수할 수 있다. 정상 조회·오타·잘못된 파일명은 일반 오류로 끝나며, 이 스테이지에는 PC 폭발이 없다.

서유진에게 대화할 수 있으며 정답 선택 퀴즈는 없다. 서류를 든 채 빈 곳을 향해 F를 누르면 상부 트레이에 돌려놓는다. 서류는 유실되거나 복제되지 않는다. 완료와 다시 해 보기를 지원하며 2·3스테이지는 아직 실행 목록에 포함하지 않는다.

## 공간·입력·저장

상세 사무실의 기존 벽·문·책상 충돌을 유지하고 창가 뒤쪽 통로에 출력 장치를 추가한다. 배치는 `print_layout.json`의 authoring anchor 기준 상대 좌표와 방향으로 정의한다. 새 프린터·종이·점검 발판차와 기존 스타일의 의자·정비 담당자를 사용한다. 플레이 중 1인칭 시점을 유지한다.

WASD·마우스·F·Space와 Android 이동·시점·상호작용·점프를 지원한다. 점프에는 0.12초 입력 버퍼와 0.10초 코요테 타임이 있다. 현장 HUD는 마우스 입력을 가로채지 않는다. 설정·게임 종료·선택 채널 업데이트는 기존 흐름을 사용한다.

기존 저장 봉투·경로는 유지하고 `stage.version=2`로 출력실 진행을 구분한다. 작업 상태·종이 적재 단계·서류 위치·의자 브레이크·발판차를 저장한다. 재실행 시 안전한 시작 위치와 저장된 장치 상태를 복원한다. 완료는 저장 성공 후 확정한다.

기존 조사 및 6단계 저장은 검증해서 보존할 수 있지만 새 출력실 진행으로 해석하지 않는다. 이전 진행이 있으면 새 게임을 고를 때 원본을 먼저 보존한다. 보존·저장이 실패하면 교체하지 않는다. 기존 조사 호환 검사와 `--legacy-investigation`은 유지한다.

## 구현과 검증

- `stages.json`: 현재 한 스테이지의 문구·명령 도움말·파일.
- `print_layout.json`: 기존 공간과 겹치지 않는 출력실 배치.
- `stages_engine.gd`: 순수한 작업·회수·전달 판정과 새/이전 저장 검증.
- `stage_world.gd`: 프린터·발판·의자·서류·페달·담당자와 실제 거리·시야 판정.
- `stages_ui.gd` · `stages_entry.gd`: 목표·터미널·대화·완료·소개.
- `unit.gd` · `stages_smoke.gd`: 빠른 취소·진행 보존·실제 점프·회수·전달·작은 화면 검증.
